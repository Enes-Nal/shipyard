# Canvas

A built-in Shipyard plugin that gives each worktree a spatial workspace. It arranges the app's live conversation and terminal views alongside browser previews for running services. Start a terminal, drag, resize, pan, zoom, and make visual links between nodes. Layouts are stored locally by worktree. Opening a node in the usual workspace is always one click away.

The links are visual references. They do not send prompts or commands between sessions.
